# 🚀 IT Services Landing Page

A modern, responsive, and animated landing page for a fictional **IT Services Company**. The project focuses on clean UI/UX, smooth animations, responsive design, and an engaging user experience.

## ✨ Features

* 🎯 Modern Hero Section with CTA
* 👨‍💻 About Us section
* 🛠️ Services showcase
* 💡 Why Choose Us section
* 💼 Portfolio / Projects
* ⭐ Client Testimonials
* 📩 Contact Section
* 📱 Fully Responsive Design
* ✨ Smooth animations and hover effects
* 🧭 Responsive navigation
* 🦶 Professional footer

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **JavaScript**
* Responsive Web Design
* CSS Animations & Transitions
